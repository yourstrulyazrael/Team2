# 02 — Plan screen

**What to build:** The starter page is replaced by the Plan screen. The
student enters total study hours, adjusts the break allowance (default
10 minutes per study hour), and adds or removes subjects with a name and
a difficulty (Easy / Medium / Hard). A live preview shows each subject's
budget. Shares: Easy 1, Medium 1.5, Hard 2.
